## Registro de Cambios Relevantes (Changelog)

A lo largo del desarrollo del laboratorio se implementaron los siguientes cambios y actualizaciones clave en la estructura del proyecto:

1. **Fusión de Ramas y Sincronización Inicial**
   * **Descripción:** Se integraron las ramas individuales de los compañeros al repositorio principal (`main`) y se sincronizó el entorno local mediante `git pull origin main` para consolidar el trabajo en equipo.

2. **Creación y Estructuración de la Página de Inicio (`index.html`)**
   * **Descripción:** Se diseñó una sección principal de bienvenida ("Inicio") para el repositorio, introduciendo la propuesta del equipo y reservando un espacio visual dedicado para la fotografía grupal del equipo.

3. **Personalización e Integración de Tarjetas de Presentación**
   * **Descripción:** Se completó la tarjeta de presentación de **Persona 1** (`persona1.html`) con los datos personales, descripción de rol y actualización de rutas a las imágenes de perfil locales (`imagenes/`).

4. **Depuración y Limpieza del Repositorio**
   * **Descripción:** Se removieron archivos duplicados sin uso (`index copy.html`) mediante `git rm` para mantener un árbol de directorio limpio y organizado.

5. **Estandarización de Navegación y Títulos**
   * **Descripción:** Se actualizaron y unificaron las etiquetas `<title>` y las barras de navegación (`<nav>`) en todos los archivos HTML para garantizar una experiencia de usuario coherente en todo el sitio web.
